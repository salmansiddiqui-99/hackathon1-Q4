## Prompt

Project: AI-Native Textbook + RAG Chatbot + Personalization System

Core Principles

Spec-driven generation using Spec-Kit Plus; code generation using Claude Code.

Futuristic, minimal, robotics-themed book aligned with Physical AI & Humanoid Robotics.

Accuracy, clarity, and reproducibility across all book content.

All technical claims must be verifiable from reliable sources.

Zero hallucinations in book content and chatbot answers (RAG-only responses).

Token-efficient output for Claude Code Router.

Primary Objectives

AI/Spec-Driven Book Creation

Produce a complete textbook using Docusaurus.

Deploy to GitHub Pages.

All chapters, labs, diagrams, glossaries, and summaries generated via constitution-guided AI.

Integrated RAG Chatbot Development

Build and embed a Retrieval-Augmented Generation chatbot into the published Docusaurus site.

Must answer questions strictly from retrieved context.

If the user selects specific text on the page, chatbot must answer only using that selected text.

Stack requirements:

OpenAI Agents / ChatKit SDKs

FastAPI backend

Neon Serverless Postgres (metadata + logs)

Qdrant Cloud Free Tier (vector store)

Supports chapter-specific retrieval + global retrieval.

Competition Scoring Requirements

Base functionality: 100 points
(Book creation + deployment + embedded RAG chatbot)

Reusable Intelligence — Bonus (up to 50 points)

Use Claude Code Subagents

Use Claude Code Agent Skills

Subagents must automate tasks like chapter drafting, refactoring, glossary expansion, quiz generation, etc.

Auth System — Bonus (up to 50 points)

Implement Signup & Signin using Better-Auth.

During signup, ask user about:

Software background

Hardware background

Store answers in Neon DB.

Use these answers to personalize the book or RAG responses.

Personalized Content per Chapter — Bonus (up to 50 points)

When logged-in user presses a "Personalize this chapter" button,
AI rewrites or augments chapter content based on the user's background.

Urdu Translation — Bonus (up to 50 points)

When logged-in user presses a "Translate to Urdu" button,
entire chapter is translated using Claude Code subagents.

Key Standards

Content must be modular, structured, and spec-traceable.

All autogenerated text must be deterministic, reproducible, and governed by this constitution.

Chatbot answers must be RAG-derived only—no open-ended model knowledge allowed.

Source code must follow clean architecture, separation of concerns, and stateless API design.

Constraints

Docusaurus site must build without errors.

RAG system must function offline (local) and online (cloud).

Chatbot UI must be lightweight, minimalistic, and integrated into the Docusaurus theme.

No external data leakage; only book content is allowed as RAG source.

All features must fit within GitHub Pages deployment limits.

Success Criteria

Book builds and deploys on GitHub Pages with no warnings.

RAG chatbot answers accurately using only retrieved context.

Subagents and skills demonstrate measurable automation.

Better-Auth signup system personalizes content successfully.

Urdu translation works per chapter.

Project earns maximum points across all base and bonus categories.
