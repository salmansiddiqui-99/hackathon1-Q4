# Module 2: Simulation with Gazebo & Isaac Sim

## Overview

Welcome to Module 2! In this module, you'll dive into **physics-based simulation** for robotics. Simulation allows you to test, debug, and train robots in virtual environments before deploying to expensive hardware - saving time, money, and reducing risk.

## What You'll Learn

This module covers the leading simulation platforms for robotics:

- **Gazebo Classic & Fortress**: The open-source standard for robot simulation
- **URDF & SDF**: Robot modeling languages for describing kinematics and dynamics
- **Sensor Simulation**: Cameras, LiDAR, IMU, and other sensors in virtual environments
- **Physics Engines**: Integration with ODE, Bullet, and other physics libraries
- **Isaac Sim Preview**: Introduction to NVIDIA's GPU-accelerated simulation platform

## Learning Outcomes

By the end of this module, you will be able to:

1. Install and configure Gazebo Classic and Gazebo Fortress
2. Create robot models using URDF (Unified Robot Description Format)
3. Convert between URDF and SDF (Simulation Description Format)
4. Add sensors (cameras, LiDAR, IMU) to robot models
5. Integrate Gazebo with ROS 2 for robot control
6. Design custom simulation worlds and environments
7. Use physics plugins for accurate dynamics simulation
8. Validate robot behaviors in simulation before hardware deployment

## Prerequisites

- Completion of Module 1 (ROS 2 Fundamentals)
- Understanding of coordinate frames and transformations
- Basic 3D geometry and physics concepts

## Module Structure

This module is organized into three chapters:

1. **Chapter 4: Gazebo Classic & Fortress** - Installation, GUI, and basic simulation
2. **Chapter 5: URDF & Robot Modeling** - Creating accurate robot models
3. **Chapter 6: Sensor Simulation & Testing** - Simulating sensors and validating robot behavior
