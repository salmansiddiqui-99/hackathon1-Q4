================================================================================
IF SOMETHING GOES WRONG
================================================================================

Problem: "Redeploy button grayed out"
  → Refresh page (F5)
  → Check you have the right permissions
  → Try again

Problem: "Deployment keeps failing"
  → Check Railway logs
  → Verify all variables have correct values
  → Check for typos

Problem: "Tests show 6 failures still"
  → Deployment might still be in progress
  → Wait 2 minutes
  → Run test again

Problem: "Can't find Variables tab"
  → Make sure you selected the right service
  → Try refreshing the page
  → Look for a menu icon (≡) at the top

Problem: "Variables won't save"
  → Check for typos
  → Make sure there are no extra spaces
  → Try refreshing and adding again
