# Module 1: ROS 2 Fundamentals

## Overview

Welcome to Module 1! In this module, you'll master the **Robot Operating System 2 (ROS 2)** - the backbone of modern robotics. ROS 2 is the industry-standard middleware for building modular, scalable robot applications.

## What You'll Learn

This module covers the core concepts and practical skills needed to build robust robot software using ROS 2:

- **ROS 2 Architecture**: Understand the distributed computing model, DDS middleware, and core design principles
- **Nodes & Communication**: Create ROS 2 nodes and implement inter-node communication patterns
- **Topics & Messages**: Master publish-subscribe messaging for sensor data and control signals
- **Services & Actions**: Implement request-response patterns and long-running tasks with feedback
- **Parameters & Launch**: Configure robots dynamically and orchestrate complex systems

## Learning Outcomes

By the end of this module, you will be able to:

1. Set up a complete ROS 2 development environment (Humble/Iron)
2. Create and manage ROS 2 workspaces and packages
3. Implement nodes that publish and subscribe to topics
4. Design custom message types and service definitions
5. Use actions for complex, long-running robot behaviors
6. Configure robot systems using parameters and YAML files
7. Write launch files to start multi-node robot applications
8. Debug and visualize ROS 2 systems using command-line tools

## Prerequisites

- Basic programming knowledge (Python or C++)
- Familiarity with Linux/Ubuntu command line
- Understanding of basic robotics concepts (optional but helpful)

## Module Structure

This module is organized into three chapters:

1. **Chapter 1: ROS 2 Architecture & Setup** - Installation, workspace setup, and core concepts
2. **Chapter 2: Nodes, Topics & Messages** - Communication fundamentals and custom messages
3. **Chapter 3: Services, Actions & Parameters** - Advanced communication patterns and configuration
